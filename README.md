# Random Placement
### [Modrinth Page](https://modrinth.com/mod/random-placement-flamingshadow)

Random Placement is a client-side Fabric mod for Minecraft that lets you place a random eligible block from your hotbar while building.

## Features

- **Random block placement:** When the feature is enabled, right-click to place a randomly selected eligible, placeable block from your hotbar.
- **Quick toggle:** Press `R` to enable or disable Random Placement.
- **Configurable keybind:** Change the toggle key in Minecraft's **Options > Controls > Key Binds** menu.
- **Client-side:** No server-side installation is required.

Only blocks that are eligible and can be placed are considered; the mod does not randomly select every item in the hotbar.

## Requirements

- Minecraft **26.3**
- [Fabric Loader](https://fabricmc.net/use/installer/) **0.19.5 or newer**
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java **25 or newer**

## Installation

1. Install Fabric Loader for Minecraft .
2. Download and install Fabric API for the same Minecraft version.
3. Download the Random Placement mod JAR.
4. Put the mod JAR and Fabric API JAR in your Minecraft `mods` folder.
5. Launch the Fabric profile.

## Usage

1. Put blocks you want to use in your hotbar.
2. Press `R` (or your configured toggle key) to enable Random Placement.
3. Right-click to place a randomly selected eligible block from your hotbar.
4. Press the toggle key again to return to normal placement.

The toggle key can be changed from Minecraft's Controls menu.
